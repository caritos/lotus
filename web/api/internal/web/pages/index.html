goweb

A small, fast place to keep your notes and the photos that go with them.

goweb is the example app that ships with the starter template. You can write notes, attach photos, and find them again from any device with a web browser. Everything is stored on the server that runs this site, and nothing is shared with anyone else.

Open the app

What you can do

  • Create an account with your email address and a password.
  • Write, edit and delete notes.
  • Attach photos to a note and see them as thumbnails.
